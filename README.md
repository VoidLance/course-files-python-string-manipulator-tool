# Python String Manipulator

A small interactive Python program for performing common operations on a string you enter.

## Features

- Convert text to uppercase or lowercase.
- Slice text using a start index and an end index.
- Display the string's length.
- Print each character on its own line.

The tool uses Python's built-in string operations and has no third-party dependencies.

## Getting started

### Requirements

- Python 3

### Run the program

From the project directory, run:

```bash
python3 "String Manipulator Tool.py"
```

On Windows, you can use:

```powershell
py "String Manipulator Tool.py"
```

Enter a string, then choose an operation from the menu. For example:

```text
Enter your String: Hello, Python!

String Manipulation Menu:
Convert the string to upper case                     -   1
Convert the string to lower case                     -   2
Slice the string from a start index to end index     -   3
Calculate the length of the string                   -   4
Display each letter on a new line                    -   5
Please enter your choice (1-5): 1
HELLO, PYTHON!
```

For slicing, enter the start index and end index when prompted. As in Python, the start index is included and the end index is excluded.
